The POS PIN keypad (pin-screen.tsx) is plain React state, not a real input — driving it with `preview_eval` by firing all 4 digit clicks in one synchronous block silently fails (React batches the clicks and reads a stale `pin` closure each time, so it never reaches length 4 and neither succeeds nor shows an error). Use separate calls per digit, one per tool call, so each click gets its own render cycle. **Update 2026-07-10**: even one-at-a-time, the `preview_click` *tool* (as opposed to `preview_eval`) reliably failed to register on these digit buttons at all — no server action ever fired (confirmed via server logs showing zero `verifyPin` calls), tried across a fresh page load, multiple reloads, and 1-3s waits between clicks. Switching each digit press to `preview_eval` with `Array.from(document.querySelectorAll('.grid.grid-cols-3.gap-3 button')).find(b => b.textContent.trim() === '<digit>').click()` worked on the very first attempt. If `preview_click` ever seems unresponsive on this keypad (or similar plain-onClick grids) again, don't assume the PIN/credentials are wrong — switch to the `preview_eval` `.click()` approach first.
