**Strategic pivot, 2026-07-19**: Melan's actual vision for `createimpact.id` was never "just KasirKu's marketing site" — he wants it to become a portal dominantly serving culinary/F&B businesses, with KasirKu as one pillar among several. This matches why the domain itself was picked over `kasirku.id` earlier (see [[deployment-status]]) — deliberately brand-neutral so it could grow beyond one product.

**Planned pillars** (his own list, in order of how "real" they are today):
1. **KasirKu** (POS/accounting software) — the only one that's actually built.
2. **Konsultan Pajak Daerah (F&B)** — regional tax consulting (PB1/pajak restoran). He confirmed his own team will deliver this directly (not a referral/directory model). Scoped as advisory/administrative pendampingan, not formal legal representation in tax disputes (that would need Konsultan Pajak Bersertifikat/USKP certification — not yet a concern since the scope is advisory).
3. **Review Biaya/COGS** — he clarified this is an *informal* cost/expense review service, NOT a statutory financial-statement audit. Important distinction: a real external audit in Indonesia legally requires a registered Akuntan Publik/KAP, which he does not have and isn't claiming to have. Because he confirmed the informal-review framing, no licensing blocker applies. **If this scope ever expands toward "audit laporan keuangan resmi," re-raise the licensing question before building/marketing anything.**
4. **Sumber Daya Gratis** (SOP templates, Stock Opname forms, cuti/izin/sakit forms, etc.) — not built yet, was the recommended "build first" pick (cheapest, no legal/staffing dependency) but the site restructuring happened first instead per his explicit request below.

**IA restructuring shipped same day** (commit `49c2e1e`), executed in this order specifically because Melan pushed back on the original "restructure homepage last" sequencing — he wanted the portal framing live immediately, even before pillars 2-4 have deep content:
- `src/app/page.tsx` ("/") is now a neutral **portal gateway** — hero framed as "Portal Bisnis Kuliner & F&B", 3 pathway cards (Aplikasi Kasir → `/kasirku`, Layanan Konsultasi → `/layanan`, Sumber Daya Gratis → `/blog` as a stand-in until a dedicated resources page exists). Still has the getSession()-redirect-to-/dashboard behavior for logged-in visitors.
- All the old KasirKu-specific homepage content (hero/carousel, jenis-usaha cards, fitur grid, pricing section, CTA) **moved to `/kasirku`** verbatim, including its own `HeroPreview`/`HomeMobileNav` components (now live at `src/app/kasirku/hero-preview.tsx` / `home-mobile-nav.tsx`, not shared with the portal page).
- New `/layanan` page for the two consulting services — WA-lead-capture style (reuses `BILLING_CONTACT`), no fixed pricing shown (project-scoped, "hubungi kami untuk konsultasi awal tanpa biaya").
- `src/lib/supabase/middleware.ts`'s public-path allowlist, `src/app/sitemap.ts`, and root `layout.tsx`'s default metadata (now "CreateImpact" not "KasirKu") were all updated to match. `/sistem-akuntansi`'s "paket lengkap KasirKu" link now points to `/kasirku` instead of `/`.
- All other existing pages (`/blog`, `/kalkulator-hpp`, `/sistem-akuntansi`, `/perbandingan`, `/panduan-akuntansi`, `/rekomendasi-alat`) were untouched structurally — their own nav/logo still link to `/`, which now correctly lands on the portal gateway instead of the old KasirKu homepage. That's intentional, not a bug.
- 41/41 vitest + tsc + eslint all clean after the move; verified all three pages (`/`, `/kasirku`, `/layanan`) render correctly in browser with correct per-page metadata titles.

**Still open / not yet built**:
- **Sumber Daya Gratis (pillar 4)** — no dedicated page yet, portal card currently just points to `/blog`. This was the recommended next build (fastest, lowest-risk) before the homepage-first request interrupted the sequence.
- **Logo — done 2026-07-19 (`4148cec`)**: Melan shared a reference image of a logo concept he'd generated elsewhere (a black "C" with a green upward arrow forming a "1" through its gap, "createimpact" wordmark, "FINANCE | SYSTEM | GROWTH" tagline) but had lost the actual file. Rebuilt the icon portion as a clean inline SVG component (`src/components/logo.tsx`, hand-derived arc/vector math, not a traced copy) and swapped it into every one of the ~17 files that showed the old plain green-box-with-"K" mark (headers, footers, both hero-preview mockups, auth-shell's dark panel). Only the icon mark was rebuilt, not the full wordmark+tagline lockup (the header slot is too small for that) — if he wants the full lockup somewhere (e.g. a future /tentang page), that's still unbuilt. **Could not visually screenshot-verify this session** — the Browser pane's screenshot/zoom actions were failing with timeouts all session (unrelated to this change, confirmed via clean server logs) — only verified via DOM/computed-style checks (shape count, dimensions, no stray "K" text left). If the icon doesn't actually look right once he sees it live, the fix is just editing the SVG path coordinates in `logo.tsx`, not a bigger rebuild.
- Homepage copy/positioning may need another pass once `/layanan` and a resources page have real traction — right now the portal page's 3 cards are somewhat asymmetric (KasirKu has a mature product behind it, Layanan is a lead-capture stub, Sumber Daya points at unrelated blog content as a placeholder).

**Header/footer unified — done 2026-07-19 (`98c66f0`)**: Melan flagged that clicking "Aplikasi Kasir" from the portal home into `/kasirku` felt like landing on a different site — every page had its own hardcoded header/footer with a different brand name ("CreateImpact" on the portal, "KasirKu" elsewhere) and a different nav. He pointed at Olsera's site as the model: one consistent header everywhere, with a "Feature" dropdown grouping many sub-pages instead of each being a top-level nav item. Built `src/components/site-header.tsx` and `src/components/site-footer.tsx`, now used identically on every public page (portal home, `/kasirku`, `/layanan`, `/blog` + articles, `/kalkulator-hpp` + `/beli`, `/sistem-akuntansi`, `/perbandingan`, `/panduan-akuntansi`, `/rekomendasi-alat`, `/terms`, `/privacy`). Brand is "CreateImpact" everywhere now (no more "KasirKu" swap on the KasirKu-specific pages). "Aplikasi Kasir" in the header is a click-toggle dropdown (not hover-only, works on touch) listing KasirKu, Harga (→`/kasirku#harga`), Kalkulator HPP, Sistem Akuntansi, Perbandingan, Panduan — mirrors Olsera's "Feature" menu pattern. Mobile gets the same items in a flat hamburger overlay. The old per-page `src/app/kasirku/home-mobile-nav.tsx` is gone, fully superseded. **Deliberately left untouched**: `/kalkulator-hpp/beli/selesai` (a minimal order-confirmation page with no nav by design, not part of the "feels like a different site" problem).

**How to apply**: any NEW public page should use `<SiteHeader />`/`<SiteFooter />` from the start, not hand-rolled header markup — that's exactly the pattern that caused this inconsistency. If asked to add content for "Layanan" or "Sumber Daya", the real routes are `/layanan` and a not-yet-created resources page (don't assume `/blog` is the permanent home for pillar 4). If asked about `createimpact.id`'s identity/positioning, it's a multi-pillar portal, not a single-product site — reflect that in copy/strategy suggestions, per [[growth-marketing-phase]].
